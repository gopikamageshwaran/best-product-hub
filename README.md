## Publish with GitHub Pages

1. Create a public GitHub repository named `best-product-hub`.
2. Upload every file and the `assets` folder from this project.
3. Make sure `index.html` is at the repository root.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select **main** and **/(root)**.
8. Click **Save**.
9. GitHub will display the public site address on the Pages settings screen.

GitHub will display the exact public URL for your repository on the **Settings → Pages** screen after publishing.

## Before Amazon reviews the site

- Publish the GitHub Pages URL and add that exact URL to your Amazon Associates account/site list.
- Confirm your Associates account information is current.
- Review the website on mobile and desktop.
- Keep the content recent and expand the site with genuinely useful original guides over time.
- Do not buy through your own affiliate links.
- Do not ask friends or relatives to purchase through your links.
- Do not copy Amazon customer reviews or star ratings.
- Do not add live price tracking.
- Do not add the Amazon logo or other Amazon trademarks unless your program terms expressly permit that use.
